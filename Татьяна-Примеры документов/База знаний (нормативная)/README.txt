База знаний (нормативная) — папка для документов, которые дополняют 44-ФЗ и 223-ФЗ.

Сами законы 44-ФЗ и 223-ФЗ сюда НЕ кладём: они уже в базе знаний отдельным путём,
текстом с официального портала pravo.gov.ru (web/src/data/laws/, скрипт
web/scripts/kb-laws.ts). Дублирование файлом создало бы два одинаковых источника
в поиске.

Три подпапки — для документов, которые владелец или команда добавляет сам:
- Подзаконные акты — постановления Правительства РФ по 44-ФЗ/223-ФЗ.
- Письма Минфина и ФАС — разъяснительные письма.
- Кодексы и специальные законы — нормы контрактной системы из ГК РФ, КоАП РФ и т. п.

Формат — любой, который уже читает проект: .docx, .pdf (с текстовым слоем), .txt.
После добавления файлов: npm run kb:folder -- --ingest --global-approver=Евгений
(из папки web, с запущенной локальной базой).
