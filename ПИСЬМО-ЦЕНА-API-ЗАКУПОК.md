# Письмо: цена доступа к данным о закупках (API)

Отправить в МультиТендер (форма «Связаться» на multitender.ru) и в Контур.Закупки (отдел продаж на kontur.ru). Одно и то же письмо, подпись и контакты вписывает владелец.

**Тема:** Запрос коммерческого предложения: доступ к данным о закупках (API) для интеграции в наш сервис

Здравствуйте!

Мы разрабатываем сервис «Тендерный юрист» — помощник для участников закупок по 44-ФЗ и 223-ФЗ (разбор документации, подготовка заявки). Хотим добавить в сервис поиск актуальных закупок и просим коммерческое предложение на доступ к данным по API.

Что нам нужно:
1. Закупки по 44-ФЗ и 223-ФЗ (оба закона, с выбором по фильтру), с этапом «подача заявок».
2. Поиск по ключевым словам (с исключением слов), по начальной цене (от — до), по датам (публикация, окончание подачи заявок), по региону и способу закупки.
3. В ответе: номер закупки, название, заказчик, начальная цена, даты, ссылка на закупку, ссылки на файлы документации.
4. Уведомления или регулярная выгрузка новых закупок по сохранённым фильтрам.

Просим сообщить:
- стоимость доступа по API (за месяц и за год) и от чего она зависит (число запросов, число пользователей);
- есть ли тестовый доступ и на какой срок;
- ограничения: число запросов в сутки, глубина истории, можно ли показывать данные нашим клиентам внутри сервиса и хранить их у себя;
- ссылку на техническую документацию API;
- условия договора для организации и для самозанятого / ИП (что подходит).
