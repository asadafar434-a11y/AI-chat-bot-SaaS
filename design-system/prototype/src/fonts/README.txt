Шрифты интерфейса: Geist и Geist Mono (Vercel).

Лицензия — SIL Open Font License 1.1: шрифты можно свободно использовать, встраивать в приложения и распространять
вместе с ними (https://openfontlicense.org). Продавать сами файлы шрифтов отдельно нельзя.

Файлы получены из Google Fonts — те же, что раньше подгружал интерфейс с fonts.googleapis.com. Это переменные шрифты:
один файл покрывает все начертания 100–900. По файлу на письменность: cyrillic, cyrillic-ext, latin, latin-ext.
Подключены в ../index.css правилами @font-face.

Зачем свои файлы, а не ссылка на Google: сервер (web/next.config.ts) по политике содержимого не пускает шрифты с чужих
сайтов, а Google Fonts узнаёт адрес каждого посетителя — для сервиса с персональными данными это лишняя передача.
