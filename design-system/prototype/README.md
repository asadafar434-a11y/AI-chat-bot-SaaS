# Прототип «Тендерный юрист»

Кликабельный прототип заявки под ключ в стиле Figma Make. Основа — код из папки «Улучшение прототипа из GitHub»
(исходник Make лежит там как есть), сюда перенесены логика продукта и правки владельца.

```bash
pnpm install          # или npm install
pnpm dev              # http://localhost:4174
pnpm build            # dist/prototype.html — одна страница, открывается двойным щелчком
pnpm typecheck
```

## Что где

| Экран | Файл | Что показывает |
|---|---|---|
| Мои закупки | `src/components/TendersDashboard.tsx` | статусы, готовность заявки, ответ специалиста, удаление |
| Путь заявки | `src/App.tsx` | 5 шагов, шапка закупки, уведомление «Специалист ответил» |
| Загрузка | `StepUpload.tsx` | файлы с площадки; импорт по ссылке ЕИС — «скоро» |
| Анализ | `StepAnalysis.tsx` | состав заявки на аукцион по ч. 1 ст. 49 44-ФЗ; сначала отсутствующее, готовое — вниз |
| Цена | `StepPricing.tsx` | «до какой цены снижаться» — тот же расчёт, что в `web/src/lib/price-floor.ts` |
| Проверка | `StepReview.tsx` | карта полей, мастер, источники, риск, «Пересчитать с ИИ» 3 раза, итоговая проверка |
| Пакет | `StepPackage.tsx` | оплата 1000 ₽, DOCX и PDF по одному или архивом, версии документов, специалист 500 ₽ |
| Поиск, история | `TenderSearch.tsx`, `BidHistory.tsx` | «скоро»: пример того, как будет |

Логика заявки — `src/lib/app-state.ts`: виды полей, риск, итоговая проверка, замечания специалиста.
Виды полей и тексты итоговой проверки — те же, что в приложении (`web/src/lib/fields.ts`).
Данные примера — `src/lib/data.ts`: закупка компьютерной техники, электронный аукцион по 44-ФЗ.

## Что в прототипе условно

- Оплата — без денег; ответ специалиста приходит через 6 секунд (в жизни — до 2 часов).
- «Пересчитать с ИИ» и «Составить заново» ИИ не вызывают — показывают, как работают лимиты:
  3 пересчёта на заявку, если данные не менялись — попытка не списывается; после 3-й версии документов — подтверждение.
- Поиск по площадкам, итоги торгов, импорт по ссылке ЕИС и формат ODT — помечены «скоро»: система их пока не умеет.
- Вероятность победы не показывается: без истории торгов заказчика её нечем честно посчитать.
