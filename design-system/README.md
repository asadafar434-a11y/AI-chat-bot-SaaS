## Что это

Библиотека UI-компонентов для AI-приложений от Vercel, построенная **поверх shadcn/ui**.
Figma-файл — зеркало кодовой библиотеки: имена слоёв = имена React-компонентов,
варианты в Figma = пропсы в коде. Поэтому дизайн переносится в код почти 1:1.

Стек, на который рассчитана система: **React 19 + Next.js 14+ (App Router) + Tailwind CSS 4 + shadcn/ui + AI SDK**.

## Установка компонентов

Ставятся поштучно, как в shadcn — исходник копируется в проект (`@/components/ai-elements/`):

```bash
npx ai-elements@latest add message conversation prompt-input response
```

Через shadcn CLI — то же самое:

```bash
npx shadcn@latest add @ai-elements/message
```

Если shadcn/ui ещё не инициализирован, первая же установка настроит его сама.

## Ключевые факты о токенах

- **База — shadcn/ui `neutral`**, но `--primary` переопределён на **синий `#155dfc`** (blue-600),
  `--primary-foreground` — `#eff6ff` (blue-50). Это отличие от стокового shadcn, где primary почти чёрный.
- **Базовый радиус — 10px** (`--radius`, он же `rounded-lg`). Отсюда `rounded-md` = 8px, `rounded-sm` = 6px.
- **Шрифт — Geist** (+ Geist Mono для кода).
- Рабочий диапазон кеглей в интерфейсе узкий: **12 / 14 / 16 px**.
  `text-sm` (14/20) — основной текст сообщений; `text-base` (16/24) — только поле ввода; `text-xs` (12/16) — метаданные.
- В тёмной теме `--border` и `--input` — **полупрозрачный белый** (10% и 15%), а не плотный серый.
  Поле ввода дополнительно получает заливку `rgba(255,255,255,0.043)`.

## Что изменено в самом файле Figma

Айдентика «Отклик» заведена **режимами переменных**, а не переписыванием значений —
поэтому всё обратимо и исходные варианты Vercel остались на месте.

| Коллекция | Новый режим | Что в нём |
|---|---|---|
| `⚙️ Primary Color` | **Отклик** | `primary` → `indigo/900` (светлая) и `indigo/300` (тёмная), плюс `sidebar-primary` и все foreground. Всё алиасами на палитру Tailwind, новых цветов не заводилось |
| `⚙️ Font Family` | **Отклик** | `font-sans` → Onest, `font-mono` → JetBrains Mono, `font-display` → Unbounded |

В коллекцию шрифтов добавлена переменная **`font-display`** (её не было — были только
`font-sans` и `font-mono`). Скоуп `FONT_FAMILY`, значение задано во всех четырёх режимах.
Привязана к заголовкам 30px на странице Demo. В компоненты дисплейная гарнитура
намеренно не заведена: там текст 12–16px, Unbounded в таком кегле нечитаем.

Режим применён ко **всем 60 страницам** файла. Исходные режимы `Blue`, `Neutral`,
`Geist`, `Inter` не тронуты — чтобы вернуться, достаточно переключить режим на странице.

### Как привязать шрифт переменной в этом файле

Неочевидно и стоило четырёх попыток. У текстовых узлов AI Elements **`fontWeight`
привязан к переменной**, и пока эта привязка стоит, семейство не разрешается —
`setBoundVariable("fontFamily", …)` молча не даёт эффекта. Повторная привязка того же
значения тоже ничего не делает: это no-op, старое разрешение остаётся.

Рабочая последовательность — ровно в этом порядке:

```js
await figma.loadFontAsync({ family: "Unbounded", style: "Regular" });
for (const seg of t.getStyledTextSegments(["fontName"])) await figma.loadFontAsync(seg.fontName);

t.fontName = { family: "Geist", style: t.fontName.style };  // 1. прямое присвоение запускает пересчёт
t.setBoundVariable("fontWeight", null);                      // 2. снять вес — он блокирует семейство
t.setBoundVariable("fontFamily", fontDisplayVariable);       // 3. теперь привязка применяется
```

Проверять результат надо по `t.fontName.family` сразу после привязки: если там
осталось прежнее семейство — привязка не сработала, экран об этом не скажет.

Ещё: Unbounded заметно шире Geist, поэтому заголовки переносились. Лечится
`textAutoResize = "WIDTH_AND_HEIGHT"` на тексте и `layoutSizingHorizontal = "HUG"`
на родительском auto-layout.

**Чего в Figma не сделано:**

- **Скругления остались прежними.** Шкала `radius/*` в коллекции `Tailwind Variables` —
  это сырая шкала Tailwind с одним режимом, где `rounded-lg` обязан равняться 10.
  Чтобы получить «мягкую» геометрию (30 / 24 / 18 / 14), нужно либо переопределить
  смысл этих токенов, либо перепривязать компоненты на более крупные ступени.
  Первое ломает семантику имён, второе — правка по каждому компоненту.
- **Дисплейная гарнитура только на странице Demo.** Переменная `font-display` заведена
  и работает, но привязана пока к десяти заголовкам демо-страницы. В остальных местах
  файла текста дисплейного кегля просто нет.

## Оговорка по числам из Figma

В экспортированном коде некоторых инстансов попадаются дробные значения
(`11.4px`, `12.8px`, `7px`) — это артефакт масштабирования вложенных компонентов на канвасе.
Канонические значения всегда берутся из переменных: `text-xs` = 12, `spacing/1_5` = 6.
В [components.md](components.md) указаны канонические.
