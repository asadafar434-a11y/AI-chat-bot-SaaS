# Инструменты

## build-razbor-docx.js

Собирает `Отклик — разбор, части 0-5.docx` из кода. Все числа финмодели
считаются в скрипте (константы вверху файла), а не вписаны в текст руками —
поэтому таблицы и выводы не расходятся между собой.

```bash
npm install docx
node tools/build-razbor-docx.js "Отклик — разбор, части 0-5.docx"
```

Ключевые константы, от которых зависит весь разбор:

| Константа | Значение | Где влияет |
|---|---|---|
| `ARPA` | 2 100 ₽ | вся выручка |
| `GM` | 0,78 | валовая маржа при смешанной маршрутизации моделей |
| `FIXED` | 18 000 ₽/мес | точка безубыточности |
| `LIVING` | 90 000 ₽/мес | кассовый разрыв в сценарии А |
| `CHURN` | 5%/мес | LTV |
| `TOK` | 8 тыс. токенов на диалог | себестоимость, самое чувствительное допущение |
| `PLAN` | новые клиенты по месяцам | вся динамика |

Поменять константу — пересобрать — числа сойдутся во всех 43 таблицах.
