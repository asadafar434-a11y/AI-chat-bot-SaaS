# Инструменты

## build-razbor-docx.js

Собирает `Отклик — разбор, части 0-5.docx` из кода. Все числа финмодели
считаются в скрипте (константы вверху файла), а не вписаны в текст руками —
поэтому таблицы и выводы не расходятся между собой.

```bash
npm install docx
node tools/build-razbor-docx.js "Отклик — разбор, части 0-5.docx"
```

Ключевые константы, от которых зависит весь разбор:

| Константа | Значение | Где влияет |
|---|---|---|
| `ARPA` | 2 100 ₽ | вся выручка |
| `GM` | 0,78 | валовая маржа при смешанной маршрутизации моделей |
| `FIXED` | 18 000 ₽/мес | точка безубыточности |
| `MKT(m)` | 5→10→20→50 тыс. ₽/мес | маркетинг по этапам |
| `CHURN` | 5%/мес | LTV |
| `TOK` | 8 тыс. токенов на диалог | себестоимость, самое чувствительное допущение |
| `PLAN` | новые клиенты по месяцам | вся динамика |

Поменять константу — пересобрать — числа сойдутся во всех 43 таблицах.

## build-doc2.js

Собирает `Отклик — разбор, части 6-15.docx`. Разбит на модули, чтобы не упираться
в лимиты при правках:

| Файл | Содержимое |
|---|---|
| `doc2-lib.js` | помощники вёрстки + **все расчёты** (модель, инфраструктура по уровням) |
| `doc2-p67.js` | части 6–7: scope MVP, этапы |
| `doc2-p89.js` | части 8–9: стек, инфраструктура |
| `doc2-p1012.js` | части 10–12: комплаенс, команда, GTM |
| `doc2-p1315.js` | части 13–15: финансы, риски, красная команда |
| `doc2-app.js` | приложения A–E + разбор ценности обычным текстом |

```bash
node tools/build-doc2.js "Отклик — разбор, части 6-15.docx"
```

**Личных расходов основателя в модели нет** — это не расход проекта. Если нужно
их учесть, прибавлять к `FIXED` в `doc2-lib.js` и к той же константе
в `build-razbor-docx.js`, иначе документы разойдутся между собой.

## build-roadmap-docx.js

Собирает `Тендерный юрист — чек-лист и дорожная карта.docx`. Пункты чек-листа,
этапы и риски — в данных вверху файла. Поменяли статус пункта (`done` / `work` /
`todo`) — пересобрали, счётчики «готово N из M» и полоса прогресса пересчитаются сами.
Галочки в документе — настоящие флажки Word, их можно ставить щелчком.

```bash
node tools/build-roadmap-docx.js "Тендерный юрист — чек-лист и дорожная карта.docx"
```
