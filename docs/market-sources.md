# Источники рыночных цен: что подключено, что нет

Составлено 22.10.2026. Правило: источник считается подключённым, только если из него в продукт реально попадают данные. Всё остальное — «не подключено» с тем, что для этого нужно. Рыночных цен и источников никто не выдумывает.

## Что работает сейчас

| Источник | Как попадает в продукт | Что даёт | Ограничение |
|---|---|---|---|
| Документы закупки | Читает код при загрузке (`spec-table.ts`, `nmck-check.ts`) | Позиции и начальные цены за единицу из бланка «Спецификация»; расчёт НМЦК заказчика (цены его поставщиков) | Цены из расчёта НМЦК дал заказчику его поставщик — для сравнения рынка они не независимы, в базу наблюдений автоматически **не** кладутся |
| Реестр контрактов ЕИС — вручную | Участник открывает карточку контракта в своём браузере и вставляет таблицу; код читает (`eis-contracts.ts`, `analog-import.ts`) | Цена за единицу, количество, НДС, дата заключения, номер контракта | С нашего сервера в ЕИС не ходим; открывается только из браузера с российским корневым сертификатом (проверено 22.10.2026 в Chrome владельца). Панель ввода сейчас скрыта с экрана закупки (решение владельца «без инпутов»), код остался |
| Любая таблица цен (ЕИС, Excel, прайс) — загрузка в общую базу | `npm run market:import` на сервере | Наблюдения в таблице `PriceObservation` с источником, датой, регионом, количеством | Только загрузка администратором (доступ к серверу и базе); без даты и источника строка не принимается |
| Курсы валют Банка России | `/api/cbr` (общедоступный ряд cbr.ru) | Динамика курса доллара, евро, юаня за год для риска «курс» | Только курсы, цен товаров нет |
| Реестры ГИСП (РПП, РЭП) | Выгрузки загружены в PostgreSQL (`registry:import`) | Реестровые номера российской продукции | Цен в реестре нет — это справочник номеров, а не цен |
| Бесплатный поиск в интернете (Brave, DuckDuckGo) | `/api/search` | Ссылки по теме риска (рост цен, тарифы), числа в выдержках — «взять» участником | Пробный, нестабильный, ссылки «не проверено» и в расчёт сами не входят |

## Отрасли

Единая расширяемая база устроена по позициям, а не по отраслям: наблюдение несёт название, единицу, ОКПД2 (если известен), регион и источник, а отрасль определяется предметом закупки (`typeOf` в `hidden-costs.ts`: товары, работы, услуги, ИТ, питание, лекарства и др.). Сегодня **данных нет ни по одной отрасли**: база заполняется только загрузкой (`market:import`), реальные выгрузки ещё не загружены. Покрытие по отраслям появится по мере загрузки; пока цена против рынка считается только по ценам, которые есть в базе или введены участником раньше.

## Правила, чтобы не выдумывать

- Наблюдение без источника и без даты не принимается; цена приводится к цене без НДС по ставке, названной при загрузке.
- Сопоставимость: та же единица, те же цифры в названии (мощность, размер, марка), похожие слова (доля общих не меньше 0,6), объёмы различаются не больше чем втрое, цена не старше 365 дней. Характеристики сверяются только по названию — глубже программа их не разбирает.
- Вывод — от пяти сопоставимых цен; ниже — «недостаточно данных» с причиной. Среднее, медиана, диапазон (10–90 процентиль от десяти цен), динамика (не меньше трёх цен в каждой части) и региональные различия (не меньше трёх цен в регионе) — только при достаточных данных. Вариация выше 33 % — вывод осторожный.
- Цены одного заказчика из его расчёта НМЦК в базу не попадают: они не независимы от его же начальной цены.
