# Расширение Chrome «Тендекс — поиск закупок в ЕИС»

Нажали «Найти» в разделе «Поиск закупок» — расширение само открывает поиск на zakupki.gov.ru в фоновой вкладке, читает до трёх страниц (до 150 закупок), закрывает вкладку и отдаёт результат в приложение. Без закладки и без вставки таблицы.

## Установка (один раз, 1 минута)

1. В Chrome откройте `chrome://extensions`.
2. Справа вверху включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите эту папку (`extension/eis-bridge`).
4. Обновите страницу приложения (`localhost:3000`): на экране «Поиск закупок» появится кнопка «Найти», а в подсказке пропадёт предложение поставить расширение.

## Что оно делает и чего не делает

- Открывает **только** поиск закупок на `zakupki.gov.ru` (адрес проверяется строго, другие не принимаются).
- Работает **только** на страницах приложения (`localhost:3000`, `127.0.0.1:3000`). Для рабочего адреса его нужно добавить в `manifest.json` → `content_scripts[0].matches`, и переустановить.
- Права: `scripting` и `tabs` (открыть и закрыть фоновую вкладку, прочитать её), доступ к `zakupki.gov.ru`. Больше ничего.
- Ходит от имени вашего браузера, как будто вы сами открыли ссылку: капчу и защиту сайта не обходит. Если ЕИС попросит подтвердить, что вы человек, откройте zakupki.gov.ru в Chrome, пройдите проверку и повторите.
- Данные никуда, кроме страницы приложения, не отправляются.

## Для разработчика

- `helpers.js` — чистые функции (проверка адреса, постраничная сборка, склейка); `background.js` — открывает вкладку и читает страницу; `content.js` — мост между страницей и расширением; `extract.js` — **собирается** командой `npm --prefix web run extension:build` из `web/src/lib/eis-copy-script.ts` (та же функция, что в закладке «Скопировать закупки»), руками не править.
- Тесты: `web/src/lib/eis-extension.test.ts` (адреса, страницы, манифест, актуальность `extract.js`).
- Страница узнаёт о расширении по атрибуту `data-tl-eis-extension` на `<html>`; запрос — сообщение `TL_EIS_SEARCH`, ответ — `TL_EIS_RESULT`.
- Как опубликовать для клиентов: Chrome Web Store (нужен аккаунт разработчика и описание политики данных); до тех пор — установка «распакованного» по инструкции выше.
