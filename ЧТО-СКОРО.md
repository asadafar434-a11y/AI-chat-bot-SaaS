# Что в интерфейсе помечено «скоро» — чтобы не забыть

Список всего, что на экране показано, но ещё не работает (или работает не полностью). Решение владельца 22.10.2026: такие кнопки **не убираем** — владелец боится про них забыть; если когда-то спрячем, они остаются в этом списке. Обновлять при каждой правке интерфейса. Напоминать владельцу в разговорах «что дальше».

| Где на экране | Что обещано | Что нужно, чтобы заработало |
|---|---|---|

| Шаг «Загрузка» → строка **«Ссылка на закупку в ЕИС»** | Импорт закупки по ссылке из ЕИС | Токен ЕИС (Госуслуги) и российский адрес сервера, сверка протокола — [web/src/server/eis/README.md](web/src/server/eis/README.md) |

| «Аналитика» → скрытые с экрана (решение владельца 22.10.2026: «никаких инпутов, всё под капотом») панели ручного ввода: договор, «Сколько это может стоить» со своими допущениями и фактами, расчёт заказчика, РИЦ со сценариями и вставкой цен из ЕИС, матрица проверок с записью своих результатов, «Ваши затраты» | Расчёты идут внутри и попадают в отчёт Word и PDF, подпись внизу экрана показывает итоги; без ввода участника цены-аналоги, РИЦ и 12 проверок матрицы остаются «нет данных». | «Аналитика» → **база закупочных цен пуста** | Цена против рынка (закупочная цена) по накопленным данным, динамика, регионы | Загрузить прайсы, предложения поставщиков, котировки (`npm run market:import`). Цены контрактов ЕИС не годятся: в них маржа победителя (решение владельца 22.10.2026). Миграция S15 на базу владельца применена 22.10.2026 |
| «Аналитика» → **живой поиск закупочных цен при открытии экрана** (сделан 22.10.2026, без кнопки) | Строка «Закупочные цены» внизу: найденное по главным позициям на сегодня | Работает, когда на сервере задан ключ модели (23.10.2026 выключали по просьбе владельца и снова включили по его «да» с ценой — поиск цен до 30 ₽ за запуск; блок «Товары и закупочные цены» появляется, только когда цены найдены), курс `USD_RUB` и включён переключатель «ИИ»; бесплатный поиск продукта нередко блокируется; бейдж цены появится только при ценах по всем позициям |
| «Аналитика» → **автоматический сбор закупочных цен из интернета** (консольная команда) | Поиск находит страницы поставщиков, платная модель читает их, код проверяет | Официальный поиск Brave платный, владелец платить не будет (22.10.2026) — вместо него страницы ищутся в Яндексе через Chrome владельца (`--urls-file`, бесплатно), сайты со скриптовыми ценами читаются через Chrome (`--pages-file`), `pulscen.ru` не пускает и его. Цены без НДС принимаются с пометкой «НДС на странице не указан» как цена без НДС (решение владельца 22.10.2026); сохранённый ответ модели можно перепроверить по новым правилам бесплатно (`--recheck`). Команда `npm run market:collect` готова (22.10.2026, прогон на угле: 3,31 ₽ за 4 страницы, 1 принятая цена); на экране кнопки нет. Для объёма нужны: официальный поиск по ключу (бесплатный поиск блокирует робота), чтение страниц, где цены подгружаются скриптом или сайт закрыт от роботов (через браузер), решение, что считать закупочной ценой с доставкой (на вагоне, самовывоз, доставка) |
| Окно **«Загрузить цены из таблицы»** (вставка карточек ЕИС в РИЦ) | Прежняя загрузка цен-аналогов из реестра контрактов | Устарело: цены контрактов расчёт РИЦ отклоняет (`price-basis.ts`); с экрана окно убрано, в коде осталось |
